# SEO Solution

**32 agents. 8 pôles. Votre équipe SEO dans Codex.**  
Par [WebSolution24](https://www.websolution24.fr/).

Préparez vos analyses, briefs, contenus et priorités SEO dans un projet dédié. Un directeur répartit les tâches entre les spécialistes ; vous relisez les livrables et validez les actions.

**[Télécharger SEO Solution — ZIP](https://github.com/Websolution24/seo-solution/raw/refs/heads/main/seo-solution.zip)**

## Installer avec un prompt

1. Téléchargez le ZIP et joignez-le à un chat Work local ayant accès aux fichiers de votre ordinateur.
2. Copiez le texte de [PROMPT_INSTALLATION.txt](PROMPT_INSTALLATION.txt) dans ce chat.
3. Suivez les étapes proposées. L’installateur prépare un dossier neuf avec les agents ; l’ajout de ce dossier comme projet peut demander un clic dans l’application.

Les instructions détaillées figurent dans [INSTALLER.md](INSTALLER.md). Python 3.11 ou plus récent est nécessaire pour l’installateur et le connecteur local.

## Vos sources de données

- **Ranxplorer** : mots-clés, concurrents et estimations de marché avec le MCP officiel. Un accès API personnel et des crédits sont nécessaires pour la collecte directe.
- **Google Search Console** : clics, impressions, CTR, positions moyennes, sitemaps et inspection d’URL via le connecteur local en lecture seule. Vous autorisez vous-même l’accès Google et choisissez la propriété du projet.
- **Vos exports** : utilisables sans connexion. Les conversions Analytics, réponses des moteurs IA et backlinks détaillés conservent leurs sources séparées.

Consultez les [outils Ranxplorer](seo/OUTILS_RANXPLORER.md), le [guide Search Console](seo/OUTILS_GSC.md) et le [budget API](seo/BUDGET_API.md). Aucun secret n’est à transmettre dans le chat ou à enregistrer dans ce dépôt.

## Lancer une première mission

Remplissez [le contexte de votre site](seo/CONTEXTE.md), ouvrez un nouveau chat du projet et utilisez le premier mandat du [guide de démarrage](LISEZ-MOI.md). Quatre enchaînements sont proposés dans [WORKFLOWS.md](WORKFLOWS.md).

Les 32 rôles forment un catalogue de spécialistes. Le directeur choisit ceux qui servent la mission, selon les capacités réellement disponibles dans votre application.

## État de cette version

Les vérifications hors ligne et leurs limites sont décrites dans [VERIFICATIONS.md](VERIFICATIONS.md). Les tests utilisent des données fictives : ils ne prouvent pas la connexion à votre compte Google ou Ranxplorer et ne garantissent aucun résultat SEO.

Le pack prépare des analyses et des brouillons. Toute publication, prise de contact, suppression ou dépense conserve la validation humaine prévue. Gardez vos exports et données clients dans votre propre projet.

Distribution indépendante d’OpenAI, Google et Ranxplorer. Voir [PROVENANCE.md](PROVENANCE.md).
